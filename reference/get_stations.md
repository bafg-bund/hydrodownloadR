# Convenience: fetch stations by provider_id

Convenience: fetch stations by provider_id

(Convenience) Get stations by provider_id

## Usage

``` r
get_stations(provider_id)

get_stations(provider_id)
```

## Arguments

- provider_id:

  Provider identifier, e.g. "DK_VANDA".

## Value

A tibble of stations; see
[`stations()`](https://bafg-bund.github.io/hydrodownloadR/reference/stations.md).
