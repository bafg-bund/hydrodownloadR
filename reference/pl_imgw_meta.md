# IMGW station metadata (packaged)

Enriched station metadata provided by IMGW (as of ; see
`attr(., "source_stamp")`). Columns (tibble): station_id, station_name,
river, lat_md, lon_md, area_md, altitude_md, vertical_datum_md.

## Format

A tibble with one row per station.

## Source

Provided directly by IMGW to GRDC.
